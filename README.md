# Hortanica

Static GitHub Pages site for `hortanica.com`.

## Structure

- `/` — Home
- `/research/` — Research index
- `/research/boundary-relative-state-time/` — Individual paper page
- `/projects/` — Engineering projects index
- `/projects/rack-scale-embedded-power-environmental-control/` — Individual project page
- `/about/` — About
- `/assets/styles.css` — Shared styles
- `/papers/` — Public manuscript PDFs

Each paper should get its own folder beneath `/research/` with an `index.html`.
This produces clean URLs such as:

`https://hortanica.com/research/boundary-relative-state-time/`

Each engineering project should get its own folder beneath `/projects/` with an `index.html`.

## Publication rule

Public manuscript files are provided as submitted manuscripts/preprints and should be clearly labeled with their current publication status.
